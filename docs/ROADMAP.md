# 路线图 / Roadmap

## 下一步：科学去除胶片整体偏色（如 Kodak Vision3 500T）
目标：在翻拍阶段精确去除胶片在拍摄光源下的整体偏色，再在 DCTL 里修正交叉偏色。

1. **片基调平**（已有）：去掉橙色片基，片基 = 目标值。
2. **整体偏色 → 灯光三通道密度偏移**：以片基为零点，在密度空间让灰参考（色卡 A1–A6 灰阶或画面中性点）三通道密度相等，反推灯光三通道亮度比例，闭环测量直到收敛。灯光改变某通道相当于该层密度整体平移，正好对应拍摄光源色温偏差（例如 500T 在日光下≈缺少 85 滤镜）。
3. **交叉偏色 → DCTL 逐通道 gamma**：三层乳剂反差不同，灯光无法改变斜率；用 A1–A6 六级灰阶测出三通道密度曲线斜率，写入 Positive_Out 的 `gam_r/g/b`（或曲线）。
4. **每种胶片一套参数预设**（500T、Portra、Ektar…），存入 filmdb / scanconfig，可直接调用并一同写入 DCTL。
5. 无灰参考时，按胶片标称平衡（500T = 3200K）套固定偏移，标注为近似值。
