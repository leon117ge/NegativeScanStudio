NegativeScan Studio v0.88

Usage:
1. Connect the camera in Camera, then go to Camera & Light > Light.
2. The light page now has the shared live view; click Start live view (if not already started) and drag the small orange box directly onto clean film base. Camera/Light/White light/Trichrome share the box.
3. In Rectangle mode, leveling is blocked until a box is actually drawn; Reset to Auto clears the shared box and restores auto detection. A box from the old v0.87 must be redrawn once, so that the original default center box is not mistaken for a manual selection.
4. When leveling finishes, it shows the film base linear R/G/B (after the matrix when a camera profile is enabled) and the light's R/G/B brightness.
5. Click "Write DCTL" to save the Film base R/G/B defaults and the Light leveling preset of FilmScan_Density_In; the next export uses them, and the DCTL page readings/presets update in sync. Existing Resolve nodes are not changed remotely; reload the DCTL / pick the Light leveling preset. CameraCal must use the same profile and strength as during leveling.
6. Copy copies time/film base/light values/box/source. Successful records are appended to %APPDATA%\NegativeScanStudio\leveling_log.csv, with times in +08:00. For Auto the normalized box is all zeros, meaning no manually selected box.
7. If the real camera TIFF re-check fails, only estimated readings are shown and "Write DCTL" is unavailable; a stop, failure or non-convergence does not write stale data.

Implementation:
Modified hdrpage.go, lightpage.go, main.go, presets.go; the four original files were first backed up as .bak_v087.
Added levelingrecord.go, levelingdefaults.go, levelingexport.go, levelingrecord_test.go, levelingdefaults_test.go.
Light is HDRUI.liveView(3); it only adds display controls and reuses the same dev/sess/worker/bmp/roi; there is no second camera connection. Leaving all pages with a camera preview stops polling, and returning resumes it as originally intended; leveling keeps using pause/resume. The old three-channel sample images are kept in the Last leveling captures (not live) collapsible section.
The write target is the base_r/base_g/base_b defaults of Density_In and the Light leveling entry of preset_base, not the density parameters of Mask/Crosstalk. The values are film base statistics from the actual trichrome TIFF/65535, through the current camera matrix (if enabled); they are not JPEG preview readings and not light percentages.
